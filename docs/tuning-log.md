# 调参记录（2026-10）

这是一轮集中调参的清单，按主题归类。目的不是“记流水账”，而是留下“当时为什么这么改”，下次出问题能对上号。

## 拟人化节奏

| 改动 | 目的 |
| --- | --- |
| 关闭冷群自动发言 | 群里没人说话时不要自说自话，避免刷屏 |
| 加入睡眠时段 | 深夜不主动打扰，符合“拟人生活”的设定 |

## 人设与表达

| 改动 | 目的 |
| --- | --- |
| 减少口癖 | 口癖过多会显得机械，也容易在长对话里重复 |
| 调整语气状态 | 让回复更像“当前情绪下的人”，而不是固定模板 |

## 知识库与 RAG

| 改动 | 目的 |
| --- | --- |
| 补充语料知识库 | 让角色背景和世界观有据可查 |
| 重新切分数据集 | 原来的切分太碎/太长，检索命中率不理想 |
| 调整人设与知识库比重 | 检索内容不能压过人设，否则会“像百科不像角色” |

## 主动行为

| 改动 | 目的 |
| --- | --- |
| 开启主动会话与私聊会话 | 不只是被动回复，也能在合适的时候开口 |
| 接入主动联网搜索 | 遇到时效性问题能查，而不是硬编 |
| 调低续话时间 | 群聊接话更快，减少“等半天才回” |

## 记忆

| 改动 | 目的 |
| --- | --- |
| 调整记忆核心 | 控制“记住什么、记多久、怎么召回”，避免上下文越滚越大 |

## 稳定性与清理

| 改动 | 目的 |
| --- | --- |
| 清理内存与日志 | 4 GiB 机器余量小，日志和缓存会慢慢吃掉空间 |
| 删除多余镜像和文件包 | 释放磁盘（当时盘已用 63%） |
| 关闭用不到的功能 | 少一个后台任务就少一份内存和故障面 |
| 清空无用插件的持久化数据 | 卸载插件后残留的数据库/缓存没有意义 |

## 修复与安全

| 改动 | 目的 |
| --- | --- |
| 修复私聊回复失败 | 一度只有主动问答能工作，被动回复链路断了 |
| 安装 `antipromptinjector` 并调参 | 防提示词注入；规则太严会误伤正常聊天，需要按群调 |
